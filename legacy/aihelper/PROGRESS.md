# 작업 진행 기록 (이어하기용)

> 작업이 끊기면 이 파일부터 읽고, 첫 번째 `[ ]` 항목부터 이어서 진행한다.
> 설계 문서: [docs/DESIGN.md](docs/DESIGN.md)

## 확정 결정 사항
- AI 연결: 강사 본인 구독 + 공식 CLI (Gemini CLI / Claude Code / Codex CLI). 수동중계·API는 보류
- 과목: 수학·과학 / 출력: DOCX
- 작업공간: 개인=로컬 폴더, 팀=Google Drive 데스크톱 앱 동기화 폴더
- **학생 답안·성적도 작업공간(팀 드라이브)에 저장** (공유 필수), **이름 마스킹 안 함**
- 앱: Python(FastAPI) + **Vite + React + TypeScript 모던 UI(빌드 산출물 포함)** + pywebview 창 (없으면 브라우저로 폴백)
- 배포: GitHub, 코드서명 없음. 설치 스크립트(uv 기반) + 추후 PyInstaller 빌드
